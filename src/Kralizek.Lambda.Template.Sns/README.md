# Kralizek.Lambda.Template.Sns

Source-specific support for AWS Lambda functions triggered by Amazon SNS.

This package is being migrated to the new `RecordFunction` programming model introduced by the next major version of `Kralizek.Lambda.Template`.

The SNS project is intentionally not part of the active solution in the core-model slice. Its public API and examples will be updated in the dedicated SNS implementation pull request before the package is released with the new major version.

Until that migration is complete, refer to the latest stable package documentation for the currently released API.
